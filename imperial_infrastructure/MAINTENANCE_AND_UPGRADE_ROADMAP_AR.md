## II. إرشادات مسح المقاييس الذرية

### نقاط النهاية المتاحة

| نقطة النهاية | التنسيق | الوصف |
|-------------|---------|-------|
| `/metrics` | Prometheus | المقاييس الكاملة |
| `/api/v1/metrics` | JSON | لقطة منظمة |
| `/api/v1/health` | JSON | حالة الخدمة |

### المقاييس الرئيسية (AtomicU64 / Relaxed)

| المقياس | المصدر |
|---------|--------|
| `total_orders` | `OrderBookManager` |
| `total_trades` | `OrderBookManager` |
| `tps_current` | `OrderBookManager.tps_count` |
| `tps_peak` | `OrderBookManager.tps_peak` |
| `fix_sessions` | `FIXGateway` |

### قواعد المسح
1. لا تمسح أسرع من مرة/ثانية (عداد TPS يُعاد ضبطه)
2. لا تصل إلى `OrderBook` مباشرة — استخدم الذريات المجمعة مسبقاً
3. `/metrics` هو نقطة النهاية الرسمية لـ Prometheus

## IV. إجراءات الترقية

### 1. ترقية التبعيات
```bash
cargo update
cargo outdated -w
cargo test --release -- --nocapture
```

### 2. إضافة ميزة جديدة
1. تحديث `DECISION_INTELLIGENCE_LOG` أولاً
2. تحديث `MASTER_ROADMAP` (إضافة إلى [الأعمال المستقبلية])
3. تنفيذ الميزة
4. تحديث `MASTER_ROADMAP` (نقل إلى [تم])
5. تحديث `SOVEREIGN_FEATURE_REGISTRY` (ربط بالطبقات)
6. تحديث `MAINTENANCE_ROADMAP` (إضافة إلى سجل الديون إن لزم)

### 3. إضافة وحدة جديدة
1. إنشاء ملف جديد في `src/`
2. إضافة `mod new_module;` في `main.rs`
3. استيراد الأنواع
4. الربط في `AppState`
5. إضافة المسارات
