## CHAPTER 4: TRADING EXCELLENCE FRAMEWORK

### 4.1 The Profit Equation

```
Profit = Sum(Spreads Captured) - Sum(Market Impact) - Sum(Adverse Selection) - Sum(Fees/Infrastructure)
```

### 4.2 The Integrated Profit Stack

```
Layer 1: SIGNAL GENERATION (alpha research, ML models, factor models)
    |
Layer 2: PORTFOLIO OPTIMIZATION (Kelly-derived sizing, risk parity, constraints)
    |
Layer 3: EXECUTION (optimal trajectories, VWAP/TWAP)
    |
Layer 4: MARKET MAKING (spread optimization, inventory management)
    |
Layer 5: RISK CONTROL (VaR/CVaR limits, drawdown gates, correlation monitoring)
```

At each layer: **Maximize expected log-growth subject to constraints on drawdown, ruin probability, and regulatory capital.**

### 4.3 Position Sizing: Kelly Criterion

```
f* = (b * p - q) / b    [Binary]
f* = (mu - r) / sigma^2  [Continuous]
```

**Critical:** Use fractional Kelly (quarter to half) — provides ~75% of growth with dramatically less drawdown.

### 4.4 Market Making: Avellaneda-Stoikov

```
Spread = 2 * (Order Processing Cost + Adverse Selection Cost + Inventory Carrying Cost)
```

Widen spreads when: inventory far from zero, volatility increases, approaching session end.

### 4.5 Optimal Execution: Almgren-Chriss

Balance urgency (execute fast = market impact) vs patience (execute slow = volatility risk). The optimal trajectory minimizes the sum of execution cost and timing risk.
