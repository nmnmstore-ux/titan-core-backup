⚡ Quickstart — 30 seconds to first order

1. Get a free API key

curl -X POST https://api.the-bridge.io/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"test","email":"you@email.com","tier":"Free"}'

2. Deposit test funds

export KEY="tb_xxxx..."
curl -X POST https://api.the-bridge.io/api/v1/wallet/deposit \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{"amount":10000}'

3. Place your first order

curl -X POST https://api.the-bridge.io/api/v1/order \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{"pair":"BTC-USDT","side":"Buy","price":65000,"quantity":0.01,"type":"Limit"}'

🔐 Authentication

All API requests require a Bearer token in the Authorization header:

Authorization: Bearer tb_xxxx_yyyyy...

Invalid or expired keys return 401 Unauthorized.
