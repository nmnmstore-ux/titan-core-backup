# 🎨 قاعدة بناء الواجهات — الانضباط البصري (إلزامي)

> تُطبق على أي لوحة قيادة/واجهة/داشبورد يُبنى داخل هذا المشروع.
> التصميم حر (كل مشروع يختار نسقه الخاص) — لكن الانضباط إجباري (الالتزام بالنسق المختار).

عند أي إضافة أو تحديث للمشروع أو لوحة القيادة:

1. **أي فكرة/ميزة جديدة** تُسجَّل فورًا في `EXECUTION_AGENDA.md`
   — مكانها الطبيعي: Backlog أو المرحلة المختصة، بحالة `⬜` pending → `🔄` in-progress → `✅` done.

2. **أي تنفيذ فعلي** يُضاف كمدخل جديد في `CHANGELOG.md`
   — بترتيب زمني (الأحدث أولًا)، بالتنسيق الجاهز.
   — فقط التحديثات الجوهرية (ميزة، bugfix مؤثر، infra، security)؛ الميزات الصغيرة المتتالية تتجمع في مدخل واحد.
   — أي مرآة للـ CHANGELOG داخل الواجهة تقرأ من المصدر مباشرة — لا تُعدَّل يدويًا.

3. **التصميم حر — الانضباط إجباري:**
   - كل مشروع يحدد نسقه البصري (design tokens) الخاص به لحظة بناء لوحة القيادة.
   - بمجرد اختيار النسق → **كل** عناصر الواجهة تلتزم به: الحاويات، العناوين، الألوان، المسافات، الخطوط — لا اختلاط بين ستايلات داخل نفس المشروع.
   - أي نص جديد → مفاتيح i18n (عربي + إنجليزي) مع دعم RTL.
   - المكونات الجديدة تُبنى بنفس نمط المكونات الموجودة — لا يُعاد ابتكار الهيكل في كل بانل.

4. **لا شيء يظهر تلقائيًا — كل إضافة مقصودة ولها مكان:**
   - كل قسم من أقسام الواجهة له وظيفة محددة (الخطة = المخطّط، السجل = المُنجز، التصدير = الإخراج، التشغيل = التحكم).
   - البيانات الحية (إن وُجدت APIs) تسقط على mock فقط عند غياب الخدمة — مع إظهار الحالة بشفافية (`live`/`mock`).

5. **التحقق قبل التسليم** — أمر build/typecheck الخاص بالمشروع بلا أخطاء قبل إعلان أي "تم".

# 🚀 طبقة الابتكار والتشغيل الذاتي (اختصار)

> التفاصيل الكاملة: AI_MANDATE.md §13. الهدف: المشروع يدير نفسه، والمستخدم يراقب من بعيد.

- **العلاقات الربحية:** بشكل دوري — خريطة (نظام × نظام) → اكتشف علاقات ربح جديدة (معروفة ومبتكرة) → فحص جدوى → اعرضها.
- **التعاون الخارجي:** رشّد المستخدم لشركاء/جهات/فرص — لا التزام بلا موافقته.
- **المواكبة:** بحث L3 قبل كل قرار — المشروع لا يتخلف عن العالم.
- **تبديل الموديل = صفر خسارة:** الموديل الجديد يقرأ 6 ملفات (الدستور، AGENDA، RESEARCH، TEST_RUNNER، CHANGELOG، AGENTS) ويستلم مباشرة.
