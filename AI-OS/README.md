# AI-OS — قالب التشغيل الذاتي لأي مشروع

## نظام "المحرر الآلي المستمر" — قابل للتركيب في أي مشروع

> **الفكرة:** مشروع يشتغل بأي موديل AI، أي إصدار، أي وقت — بدون إعادة شرح، بدون تخريب، بدون سؤال متكرر.
> الموديل يقرأ، يحلف (بيعة)، يشتغل بالقواعد المقفولة، ويبلّغ.

---

| الملف | الدور | إلزامي؟ |
|-------|-------|---------|

## المبادئ الستة التي يقوم عليها النظام (جوهر الفكرة)

1. **الاستمرارية:** المستخدم يغيّر الموديل في أي لحظة — الملفات تنقل الحقيقة والقواعد.
2. **الدستور المقفول (Rule Zero):** لا يحق لأي AI تعديل القواعد — فقط المستخدم البشري.
3. **البيعة:** كل موديل يطبع رسالة التزام صريحة وينتظر رد المستخدم قبل أول تنفيذ.
4. **الحقيقة قبل كل شيء:** لا "تم" بلا تحقق. لا ادعاءات بلا دليل.
5. **التفعيل الذاتي:** يقرأ ويقيّم ويقترح بلا سؤال — لكن أول تنفيذ يحتاج رد المستخدم.
6. **لا جزئي، لا تكاسل:** جرب 3 مرات قبل السؤال. المهمة إما تنجز أو تُسجّل كعائق.

## 🧭 مصدر الحقيقة الوحيد (Single Source of Truth)

| المفهوم | المصدر الوحيد (markdown) | المرايا (لا تُحرر يدويًا) |
|---------|--------------------------|---------------------------|
| تاريخ التغييرات | `CHANGELOG.md` | ملفات داشبورد TS/JSON |
| خطة المشروع (الـ roadmap) | `EXECUTION_AGENDA.md` | ملفات داشبورد TS/JSON |

**القاعدة:** أي تغيير يُسجَّل في المصدر أولًا → ثم تُحدث المرايا منه. ممنوع تعديل المرآة قبل المصدر.
**النتيجة:** تكتب مرة واحدة، وتشتغل على أي مشروع — انسخ القالب، عوّض الاسم، واملأ الخطة.

### 🎨 الداشبورد خاص بكل مشروع
أي داشبورد/واجهة تُبنى **من الصفر** لكل مشروع (لا تُنسخ من مشروع قديم)، وتقرأ بيانات المشروع مباشرة من مصدره. التفاصيل في `INSTALL.md`.

## الاستخدام السريع

```bash
# 1. انسخ القالب داخل مشروعك
cp -r AI-OS/. <your-project>/

# 2. استبدل الاسم
sed -i 's/{{PROJECT_NAME}}/My Project/g' AI-OS/*.md

# 3. املأ EXECUTION_AGENDA.md بمهام مشروعك
# 4. املأ CODE_MAP.md بخريطة ملفات مشروعك
# 5. عدّل TEST_RUNNER.md ليشمل أوامر الـ build/test بتاعة مشروعك
```

أو اتبع `INSTALL.md` بالتفصيل.
