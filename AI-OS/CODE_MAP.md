## 4. قواعد التعديل

1. **اقرأ الملف أولاً** قبل تعديله — افهم مكانه في الخريطة.
2. **أي تغيير في بنية (struct/type/API)** = ابحث عن كل call sites بـ grep وحدّثهم جميعاً.
3. **الملفات الحساسة** — اختبر بعد كل تعديل.
4. **الملفات السرية (`.env`, keys)** — لا تُعدّل إلا للإعدادات، ولا ترفعها.
5. **الملفات الميتة** — حددها وسمّها، لا تبني عليها.
